# DreamDecor — Interior Design Portfolio Project

Stack: HTML, CSS, Node.js + Express.

This is a resume-ready academic/demo implementation based on the supplied UI/UX journal. The journal describes categorized design browsing, design details, conceptual payment, admin designer allocation, and an AI room-preview feature.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000

## Your images
Put your own images in `publicassets/` and replace the placeholder filenames in the HTML/JS.
Recommended names:
- hero.jpg
- living-room-1.jpg
- bedroom-1.jpg
- kitchen-1.jpg
- office-1.jpg
- balcony-1.jpg
- bathroom-1.jpg
- profile.jpg

The AI screen is intentionally a portfolio/demo simulation: it uploads and previews the user's room image and applies a visual style treatment. Do not claim that it is a real generative-AI model unless you connect one.
